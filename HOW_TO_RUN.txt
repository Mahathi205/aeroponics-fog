========================================================================
🌱 AEROPONICS FOG IOT PROJECT - QUICK START GUIDE
========================================================================

Hi! Here is how to run this project on your laptop in 2 simple steps:

STEP 1: INSTALL DEPENDENCIES
Open Command Prompt (cmd) or PowerShell inside this folder and run:
    pip install -r requirements.txt

STEP 2: RUN THE ENTIRE SYSTEM
Run this single command:
    python run_all.py

------------------------------------------------------------------------
WHAT HAPPENS WHEN YOU RUN IT:
------------------------------------------------------------------------
1. It automatically launches:
   - A local MQTT Broker (on localhost:1883)
   - The Aeroponic Sensor Simulator (sensor_simulator.py)
   - The Fog Computing Node (fog_node.py)
   - The Interactive Web Dashboard (dashboard.py)

2. Your browser will automatically open at:
   http://localhost:8501
3. Use the page navigation to open 'iFogSim Digital Twin'. The first
   simulation run compiles the bundled iFogSim2 model. Java 21+ JDK (both
   java and javac available on PATH) is needed for this page's run button.

------------------------------------------------------------------------
HOW TO DEMO / TEST ON THE DASHBOARD:
------------------------------------------------------------------------
- LIVE SENSORS: Watch the 6 sensor readings update every 2 seconds.
- AUTOMATIC MISTING: If humidity drops below 70%, the pump turns ON.
  When humidity exceeds 85%, it turns OFF.
- MANUAL CONTROL: Click 'Pump ON', 'Pump OFF', or 'AUTO' in the sidebar.
- FAULT INJECTION: Click buttons like 'Stuck Sensor', 'Out of Range',
  'Sensor Offline', or 'Pump Failure' to see instant edge detection.
- PYTHON TIMING DEMO: Toggle 'Simulate Cloud Processing' to see the
  local decision routine versus the configured artificial cloud delay.
  This is not end-to-end network latency.

- IFOGSIM DIGITAL TWIN: Choose the sensor-zone count, WAN delay, and
  simulation duration, then run the fog + cloud comparison. The dashboard
  charts the real iFogSim loop outputs and offers a CSV download.

------------------------------------------------------------------------
IFOGSIM2 DIGITAL TWIN (INTEGRATED INTO THE STREAMLIT PROJECT)
------------------------------------------------------------------------
See ifogsim/README.md. The official iFogSim2 source and required libraries
are already included. On a machine with a Java JDK, use the dashboard's
'iFogSim Digital Twin' page or run:
    python ifogsim/runner.py --mode both --sensors 3 --wan-ms 100 --seconds 300
Both paths run the actual Java simulator and save one CSV per placement.

To stop the system: Press Ctrl + C in the terminal window.
For complete academic notes, diagrams, and viva Q&A, open README.md.
